## 📋 متطلبات التشغيل

- **Node.js** الإصدار 18 أو أحدث
- **npm** (يأتي مع Node.js)

---

## 🚀 طريقة التشغيل على Laragon

### الطريقة 1: تشغيل مباشر (الأسهل)

1. **ثبّت Node.js** إذا لم يكن مثبتاً:
   - افتح Laragon
   - اذهب إلى: `Menu > Tools > Quick add > Node.js`
   - أو حمّله من: https://nodejs.org

2. **انسخ مجلد المشروع** إلى:
   ```
   C:\laragon\www\daffa-platform
   ```

3. **افتح Terminal في Laragon:**
   - اضغط على زر `Terminal` في Laragon
   - أو افتح CMD واكتب:
   ```bash
   cd C:\laragon\www\daffa-platform
   ```

4. **ثبّت المكتبات:**
   ```bash
   npm install
   ```

5. **شغّل المشروع:**
   ```bash
   npm run dev
   ```

6. **افتح المتصفح على:**
   ```
   http://localhost:3000
   ```

---

### الطريقة 2: بناء نسخة إنتاجية (للنشر)

1. **بناء المشروع:**
   ```bash
   npm run build
   ```

2. **سينتج مجلد `dist`** يحتوي على الملفات الجاهزة

3. **انسخ محتوى مجلد `dist`** إلى:
   ```
   C:\laragon\www\daffa-platform
   ```

4. **افتح المتصفح:**
   ```
   http://daffa-platform.test
   ```
   (إذا كان Laragon Auto Virtual Host مفعّل)

   أو:
   ```
   http://localhost/daffa-platform
   ```

---

### الطريقة 3: معاينة النسخة الإنتاجية

```bash
npm run build
npm run preview
```

سيفتح على: `http://localhost:4173`
